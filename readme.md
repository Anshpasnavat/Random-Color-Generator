# Random Color Generator

A simple web application that generates a random HEX color when the **Generate Color** button is clicked.

The generated color is displayed on the screen and is also applied as the background color of the page.

## Features

- Generates a random HEX color
- Displays the generated color code
- Changes the background color
- Generates a new color on every button click

## Technologies Used

- HTML
- CSS
- JavaScript

## How It Works

1. Click the **Generate Color** button.
2. JavaScript generates a random HEX color.
3. The color code is displayed on the page.
4. The background changes to the generated color.
